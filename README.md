# Hexa FM

A fork of the Open Source 6 Operator FM Synth Dexed with a highly usable GUI and preset management.

> Status: Early alpha / beta. The project is actively being developed and the GUI and workflow are still being refined.

## Current status

- Currently testing in Ableton 12.
- Resizing of GUI works in Craft Anything using Claude Code but does not work reliably within the DAW when dragging or using settings.
- Resizing font size within settings causes juddering.
- Plugin formats, standalone builds, and installers are still to be fully tested and uploaded.
